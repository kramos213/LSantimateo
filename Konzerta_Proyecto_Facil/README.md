Este proyecto es **independiente** del directorio `Proyecto_Konzerta`. Se creó a partir del notebook existente, sin sustituir ni borrar el trabajo original. Conserva su análisis y añade explicaciones para facilitar la defensa del curso.

## Cómo utilizarlo

1. Instalar Python 3.12 y ejecutar `python -m pip install -r requirements.txt` desde esta carpeta.
2. Copiar el archivo original `Konzerta 08-oct-2026.xlsx` en `datos/bronce/`. También se puede utilizar el archivo de la carpeta vecina `Proyecto_Konzerta/datos/bronce/`.
3. Abrir `notebooks/Konzerta_Explicado.ipynb` con Jupyter y ejecutar todas las celdas **en orden**.
4. Revisar las tablas, gráficos y archivos exportados en `datos/plata/` y `datos/oro/`.
5. Explicar los resultados con cifras que se obtengan de la ejecución real; no inventar conclusiones.

**Google Colab:** colocar esta carpeta en `Mi unidad/Konzerta_Proyecto_Facil`, incluido el Excel en `datos/bronce/`.
